# 薛生白湿熱病篇

## 篇首の按語（原文）

【王孟英】雄按：江本呉本倶作湿温。

【王孟英】雄按：此篇始見於舒松摩重刻《医師秘笈》、後云是薛作、章氏従而釈之、而江白仙本以附陳作後、呉子音《温熱贅言》連前篇併為一人之書、並不標明何人所著、但曰寄瓢子述、且前篇之末、有「今補薛生白先生一法於後」云云、則此篇亦非薛著矣。其江本所補一法、又無薛生白三字、且此篇張友樵所治酒客之案、但称曰余診。言人人殊、無従覈実、姑存疑以質博雅。
